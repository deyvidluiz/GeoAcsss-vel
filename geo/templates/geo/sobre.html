Sobre o GeoAcessível

Objetivo

O GeoAcessível é um site educacional de Geografia para estudantes do Ensino Médio. O conteúdo foi organizado em blocos curtos, com exemplos, resumo e atividades para apoiar o estudo gradual.

A proposta considera estudantes com TEA ao priorizar previsibilidade, navegação clara, foco visível, pouco movimento e controles de fonte, contraste e redução de estímulos.

Tecnologias

  • Python e Django
  • HTML, CSS e JavaScript puro
  • Bootstrap via CDN
  • SQLite padrão do Django
  • localStorage para progresso e preferências
